\begin{abstract}

传统文本检索增强生成（RAG）在处理图文混排、跨页引用和结构复杂的长文档时，存在视觉信息丢失、结构关系不足和证据链不可解释等问题。本文设计并实现了一个多模态 GraphRAG 文档问答系统，围绕``FAISS 向量索引 + networkx 异构文档图 + 页面图像 + 视觉语言模型''的技术路线，实现了从文档入库、结构化解析、向量索引与知识图谱构建到多模态检索与答案生成的完整链路。系统使用 PyMuPDF 渲染 PDF 页面图像，调用 qwen3-vl-8b-instruct 进行结构化抽取，将文本、表格、图表、结论、关键词和关系同时写入 FAISS 索引和异构文档图谱；在问答阶段融合向量语义召回、图谱邻域扩展和社区级全局补充，最终由 VLM 基于多模态证据生成可追溯引用的答案。

实验方面，基于 12 篇 ESG 报告构建了 120 道覆盖六种类型（文本定位、表格问答、图表理解、跨页延续、多跳关系、引用追踪）的自建测试集，通过五组消融实验系统评估各组件贡献。结果表明，完整系统在全部指标上均最优（ANLS 0.084、Token F1 0.619、Heuristic Judge 0.481、证据页面召回率 0.925），验证了``向量检索 + 图谱扩展 + 多模态融合''路线的有效性。消融分析揭示 FAISS 语义召回是最关键的单一组件，而知识图谱和页面图像对证据定位和视觉推理起到了重要补充作用。

\end{abstract}
